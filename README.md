# Videos-embajador

Videos animados "Pregunta del día" para la cuenta de Instagram @mario.moreno_dg (Embajador Tecmilenio Durango).

- `pregunta-del-dia/` — videos publicados (MP4 vertical 1080x1920).
- `generador/pdd.py` — script que genera cada video: `python3 generador/pdd.py salida.mp4 generador/preguntas/pdd-XX.json`.
- `generador/preguntas/` — una pregunta por archivo JSON (num, categoria, pregunta, opciones, correcta, dato).

Reglas de contenido: sin temas políticos, fiscales ni polémicos; sin la carrera de Contabilidad (aún no abierta en el campus); no repetir preguntas ya usadas.
